# Screenshots

Product UI captures used on the Marreq public website.

## Files

| File | Description |
|------|-------------|
| `dashboard.png` | Project overview |
| `requirements.png` | Requirements list |
| `requirement-detail.png` | Requirement detail |
| `matrix.png` | Traceability matrix |
| `tests.png` | Verification management |
| `categories.png` | Categories / applicability |
| `hero-dashboard.webp` | Optimized hero image |

## Guidelines

- Prefer 1920×1080 PNG for gallery assets
- Keep file sizes reasonable for GitHub Pages
- Capture meaningful product workflows rather than settings-only screens

## Capturing updates

1. Run Marreq (see [INSTALL.md](https://github.com/MarreqSW/Marreq/blob/main/INSTALL.md) in the main repo)
2. Open the SPA (Docker `:8080` or Vite `:5173`)
3. Capture pages and replace the matching filenames here
